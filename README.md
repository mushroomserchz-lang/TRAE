# TRAE

A custom Fabric 1.21.1 mod that adds a god-tier weapon and matching armor set.

Features:
- Legendary sword: `Gods Edge`
- Overlord armor set
- Massive damage and area-of-effect burst effects
- Strong visual effect loop when wearing the full set

## Build

Install JDK 21, then run:

```bash
gradle build
```

If you prefer using the wrapper script:

```bash
./gradlew build
```
