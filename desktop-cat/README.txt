桌面小猫 1.0
====================

【先看这里：打不开怎么办】
1. 先解压到本地文件夹，不要在压缩包里直接双击 exe。
2. 右键 exe → 属性 → 如果最下方有“解除锁定 / Unblock”，勾选 → 确定。
3. 双击后如果出现蓝色窗口“Windows 已保护你的电脑”：点“更多信息”→“仍要运行”。
4. 双击没反应，多半是被杀毒软件拦截了：
   打开“Windows 安全中心 → 病毒和威胁防护 → 保护历史记录”，
   找到被拦截的文件，选择“允许在设备上运行”/恢复。
   （Go 程序常被误报，本程序不联网、不写注册表、不改系统文件、不自动启动。）
5. 位数选择：
   - 64 位系统 → DesktopCat_x64.exe
   - 32 位系统或不确定 → DesktopCat_x86.exe（32 位版在 64 位系统也能跑）
   查看方法：Win+R 输入 winver 看版本；右键“此电脑”→属性看“系统类型”。
6. 需要 Windows 7 及以上（XP 不支持）。

【怎么玩】
- 双击运行，猫咪出现在屏幕右下角、任务栏上方。
- 左键拖动：把它拎起来、甩出去，它会有重力下落和弹跳。
- 鼠标停在它身上：摸头，冒爱心。
- 单击：跳一下并喵一声。
- 双击：翻跟头。
- 右键：打开菜单
  摸摸头 / 跟着鼠标 / 去睡觉 / 声音 / 换毛色 / 跳一下 / 总在最前 / 再见啦
- 退出：右键菜单 → 再见啦。

【说明】
- 这是纯娱乐桌面宠物，不是病毒：不联网、不写文件、不写注册表、
  不设置开机启动、不复制传播。
- 免安装，删除 exe 即彻底卸载。
